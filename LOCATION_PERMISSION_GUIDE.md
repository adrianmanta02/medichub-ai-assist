# How to Enable Location Permission

If your browser is blocking location access, here's how to enable it:

## Chrome / Edge (Chromium)

1. **Click the lock icon** (🔒) in the address bar
2. Find **"Location"** in the permissions list
3. Change from **"Block"** to **"Allow"**
4. Refresh the page

**Or via Settings:**
1. Click the three dots (⋮) → **Settings**
2. Go to **Privacy and security** → **Site settings**
3. Click **Location**
4. Make sure it's not blocked
5. Under "Allowed to use your location", add `localhost` or your site URL

## Firefox

1. **Click the lock icon** (🔒) in the address bar
2. Click **"More Information"**
3. Go to **Permissions** tab
4. Find **"Access your location"**
5. Change to **"Allow"**
6. Refresh the page

**Or via Settings:**
1. Go to **about:preferences#privacy**
2. Scroll to **Permissions** → **Location**
3. Click **Settings...**
4. Make sure your site is not blocked

## Safari (Mac)

1. **Safari** → **Settings** (or **Preferences**)
2. Go to **Websites** tab
3. Select **Location** in the left sidebar
4. Find your site and set to **"Allow"**

## Quick Fix

1. **Look for the location icon** in your browser's address bar
2. Click it and select **"Always allow"** for this site
3. Refresh the page

## Why Location is Needed

Location access helps the app:
- Show clinics and pharmacies near you
- Calculate distances accurately
- Provide better recommendations
- Center the map on your location

## Note

The app works without location! It will use a default location (Bucharest center) if permission is denied. You can still:
- Search for clinics manually
- View all clinics on the map
- Use all features except location-based recommendations
